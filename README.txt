MCRM Client Journey Assessment — GitHub Pages package

Upload the extracted contents of this ZIP to the root of a GitHub repository.
Keep index.html, app.js, styles.css, .nojekyll and the assets folder together.

In repository Settings > Pages, choose Deploy from a branch, select your branch and / (root), then Save.
The site will be available at the GitHub Pages address displayed there.

No build command or dependencies are required. Relative asset links support a repository URL such as https://USERNAME.github.io/REPOSITORY/.

This is the same simulation as the matching SCORM package, including the new contact flow, continuous listing scroll, separate Gallery and Floor plans saves, opening a listing before copying its number, flexible listing copy, Saira's lower-floor feedback scenario with optional Notes, and the offer date prefilled to 16 October 2026.

Standalone progress is saved in the learner's browser. GitHub Pages does not record LMS completion or scores. Use the separate SCORM ZIP for an LMS.

This package is ready to upload; no repository or live site has been created or changed.
